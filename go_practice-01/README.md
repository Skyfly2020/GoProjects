# Практическая работа № 1 — знакомство с Go

Учебный проект по курсу GO

## Программы

- `main.go` — первая программа с приветствием.
- `cmd/experiments` — работа с переменными и типами данных.
- `cmd/card` — карточка участника курса.
- `cmd/time-converter` — перевод минут в часы с проверкой ввода.

Исходный код находится в папке `go_practice-01`.
